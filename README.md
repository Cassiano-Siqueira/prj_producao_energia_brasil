# Produção de Energia no Brasil (2015-2024) ⚡

Projeto de Análise e Visualização de Dados desenvolvido para a disciplina de Linguagem de Programação. O objetivo é analisar a matriz energética brasileira, identificando fontes predominantes, tendências de energia renovável e impactos ambientais.

## 🚀 Tecnologias Utilizadas
- Python, Pandas, Plotly
- Streamlit (Dashboard)
- Jupyter Notebook (Análise Exploratória)

## 📁 Estrutura do Projeto
- `app.py`: Código-fonte do Dashboard
- `notebooks/`: Análise exploratória de dados
- `dados/`: Bases de dados utilizadas
- `index.html`: Página de apresentação
